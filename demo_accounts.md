## 🔑 Quick Test Scenarios

### Scenario 1: Customer Books a Service
1. Login as **Demo Customer** (`customer@demo.com` / `demo1234`)
2. Click **Book a Service** → Select a category (e.g., Plumbing)
3. Choose urgency, date & time slot
4. Describe the problem → Run Smart Matching
5. Confirm booking → Track live status

### Scenario 2: Provider Manages Jobs
1. Login as **Rahim Electronics** (`rahim.electronics@demo.com` / `demo1234`)
2. Go to **Jobs Queue** → See incoming requests
3. Accept a job → Update status (On the Way → In Progress → Completed)
4. Go to **Availability** → Toggle time slots on/off

### Scenario 3: Full End-to-End Flow
1. Login as customer → Book a service
2. Logout → Login as the matched provider
3. Accept the job → Progress through stages
4. Logout → Login as customer → See completed status, invoice, and rate the provider
